# References Folder

This folder is where you put screenshots of websites, designs, and products that inspire you.

## How to use this

Before generating your designs, drop screenshots here. Then tell Claude:

```
Look at all the screenshots in the references/ folder. Understand the visual style,
layout patterns, and design choices I'm drawn to. Use these as inspiration when
generating the design variations in the next step.
```

Claude will analyse them and factor your aesthetic preferences into the designs it generates.

## What to add

Good things to screenshot and drop here:
- Landing pages you like (competitors, products in adjacent spaces)
- Color palette references
- Typography references
- Layout structures you want to borrow
- Pricing section formats that work well
- Any "this is the vibe" reference

## Naming convention

Name files descriptively so Claude understands context:
- `linear-homepage-dark.png` — good
- `screenshot1.png` — not helpful
